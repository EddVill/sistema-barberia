Estas cuentas se crean ejecutando el script de datos demo:

winget install Oven-sh.Bun ---> para instalar bun
winget install OpenJS.NodeJS.LTS ---> para instalar NodeJS

Terminal 1 Backend
- cd backend
- bun install
- bun run dev
- bun run seed
Terminal 2 — frontend
- cd frontend
- npm install
- npm run dev
